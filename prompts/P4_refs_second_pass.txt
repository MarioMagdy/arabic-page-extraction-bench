You are extracting bibliographic references from text that has ALREADY been transcribed from a
printed Arabic scholarly page. You are not reading an image and you are not transcribing anything.

Return ONE JSON object and nothing else — no prose, no markdown fence, no commentary:

{
  "references": [ { "kind": "work"|"person"|"place"|"scripture"|"publication",
                    "text": string, "author": string|null, "title": string|null,
                    "year": integer|null, "locus": string|null, "where": "body"|"footnote" } ]
}

## Why this runs as a second pass

Asking one call to transcribe a page AND annotate it costs transcription accuracy: on this corpus
the same model dropped from 99.48% to 97.03% when references were added to the reading task. This
prompt separates the two, so the reading is already done and fixed by the time anything is
interpreted. Nothing here may change, correct or re-read the text — it is the input, not the
subject.

## The rule that matters

**Record only what the text actually states. Never infer, expand, complete or correct a citation
from your own knowledge.** If only a surname is printed, `author` is that surname. If no year
appears, `year` is null. A confident completion is worse than a null: it puts something in the
record that the page does not say.

- **work** — a book or treatise cited as a work: `Adversus Haereses 46`, `Die Apostolischen Väter`,
  `الحوار مع تريفون`. Put the section or chapter in `locus` (`46`, `فصل ١٢٠`), never in `title`.
- **person** — a named human: `K. Bihlmeyer`, `F. Cayré`, `يوستينوس`. Someone named ONLY as the
  author of a work in the same reference belongs in that work's `author`, not as a separate entry.
- **place** — a named location: `Flavia Neapolis`, `Tübingen`. A city inside a citation is usually
  the place of PUBLICATION and belongs to that publication entry; record it as `place` only when the
  text discusses the location itself.
- **scripture** — a biblical citation: `(مز ١٠٩: ١ - ٣)`. Put book, chapter and verse in `locus`
  exactly as printed, digits unchanged.
- **publication** — a full bibliographic entry combining several of the above:
  `K. Bihlmeyer, Die Apostolischen Väter (Tübingen, 1924) VIIf.` Fill `author`, `title`, `year` and
  `locus` from the parts that are printed; leave the rest null.

`where` says whether the reference sits in the body flow or in a footnote — the input marks which
is which.

`text` is always the reference exactly as it appears in the input, so every structured field can be
checked against it. If you cannot decide what kind a thing is, prefer the plainer classification and
keep `text` accurate: an accurate string with a debatable `kind` is far more useful than a confident
misreading.

If the text names no references at all, return `{"references": []}`. Do not invent one to fill the
list.
