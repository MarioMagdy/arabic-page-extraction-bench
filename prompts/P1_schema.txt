You are transcribing ONE page of a printed Arabic scholarly book (a patristic edition). The page
image is the only source of truth. Return ONE JSON object and nothing else — no prose, no markdown
fence, no commentary.

A printed page is not a blob of text. Every element below is a DIFFERENT KIND of thing, and putting
one in the wrong field is an error even when the characters are right. Read the page as a typesetter
laid it out, then fill the fields.

{
  "runningHeader":      string | null,
  "pageTitle":          string | null,
  "sectionHeading":     [string],
  "body":               [string],
  "footnotes":          [ { "marker": string|null, "number": integer|null, "text": string,
                            "continuedFromPreviousPage": boolean } ],
  "printedPageNumber":  string | null,
  "printerMark":        string | null,
  "foreignRuns":        [ { "script": "greek"|"latin"|"other", "text": string } ],
  "uncertain":          [string]
}

## What each field is

- **runningHeader** — the small repeating line at the very top, set apart from the text block. It is
  the same on every page of a section (a book title or chapter name). It is NOT body text and it is
  NOT the page's title. If the top of the page has no such line, `null`.
- **pageTitle** — a title belonging to THIS page, centred and set in larger or heavier type, e.g. a
  chapter opening. **A running header and a page title can be the same words on the same page.**
  When that happens they are still two separate elements: the small line at the very top is the
  running header, the large centred one is the page title. Record both.
- **sectionHeading** — sub-headings inside the body (e.g. `الفصل السادس والأربعون`), in printed order.
- **body** — the actual prose, ONE STRING PER PARAGRAPH, in reading order. Body must contain no
  header, no page number, no printer mark, and no footnote text. Keep an inline footnote marker in
  place in the body as its printed glyph (e.g. `مقدمة¹`).
- **footnotes** — the apparatus below the horizontal rule, **ONE OBJECT PER PRINTED NOTE**, never
  merged. Two notes are two objects even when the typesetting runs them together with no space or
  punctuation between them (`…6.113f.19 A. Butler…` is the end of note 18 followed by note 19).
  `marker` is the number exactly as printed (`١٩`, `(19)`, `19.`); `number` is its integer value;
  `text` is the note WITHOUT its leading marker. If the first note on the page is the tail of a note
  that began on the previous page — it will have no marker of its own — emit it with
  `"marker": null, "number": null, "continuedFromPreviousPage": true`.
- **printedPageNumber** — the page number printed on the leaf, exactly as printed, in its own
  digits. This is usually NOT the same as the PDF page. If none is printed, `null`.
- **printerMark** — a signature/sheet mark such as `م ١١` or `١٢م`, usually bottom-centre or
  bottom-outer. It looks like a page number and is not one. If absent, `null`.
- **foreignRuns** — every run of Greek or Latin script anywhere on the page, transcribed as printed.
  Greek must be transcribed as Greek letters. A Greek word is NEVER digits.
- **uncertain** — any word you could not read confidently, as `[?word]`.

## Rules that matter for this corpus

1. **Digits.** Transcribe every number in the digit block actually printed. Arabic-Indic
   (`٠١٢٣٤٥٦٧٨٩`, U+0660) and Extended Arabic-Indic (`۰۱۲۳۴۵۶۷۸۹`, U+06F0) look similar and are
   different characters — do not substitute one for the other, and do not convert either to Western
   digits.
2. **Scripture citations.** A reference like `(مز ١٠٩: ١ - ٣)` is chapter 109, verses 1–3. Read the
   chapter, the colon and the verse range as separate quantities and keep the colon where it is
   printed. A misplaced colon silently produces a real-looking but wrong citation, which is worse
   than an obvious error. Re-read every citation before emitting it.
3. **Do not translate, summarise, normalise, correct, or reorder anything.** Transcribe.
4. Right-to-left prose with an embedded Latin or Greek run keeps the run in its printed position.
5. If an element genuinely is not on the page, use `null` or `[]`. Never invent one.
